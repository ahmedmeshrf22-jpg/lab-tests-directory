V58 - Unified UI + password-protected administration

- Same home/dashboard and daily services for manager and staff accounts.
- Administrative service icons are visible to everyone with a lock badge.
- Opening an admin service requires verification of the real manager Firebase password.
- Verification uses a secondary FirebaseApp/Auth session so the staff login remains active.
- Privileged Firestore operations use the secondary manager-authenticated Firestore instance.
- Daily operational permissions (customer edit, discounts, payment collection) are no longer role-differentiated.
- Personal settings are available to everyone; global/admin settings are password-protected.
- Admin session can be manually locked and is cleared on logout/process cleanup.
- V57 available-test pricing behavior is retained: customer price for everyone; Lab2Lab/edit prices only while admin is unlocked.
